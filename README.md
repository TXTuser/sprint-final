# Проект — Веб-планировщик задач

Приложение позволяет создавать задачи и хранить их в базе данных.
С задачами можно выполнять базовые действия: создавать, изменять, получать список и удалять.

## Цель проекта

Ранее в колледже я уже сталкивался с backend-частью веб-приложений при защите диплома (React + Node.js).
Поэтому во время выполнения этого проекта мне было немного проще понимать общий принцип работы сервера.

В процессе работы я смог освежить и закрепить знания Go и backend-разработки:

* как сервер принимает и обрабатывает HTTP-запросы;
* как тестировать API;
* как соединять backend с готовым frontend;

## Задания повышенной сложности
Задания повышенной сложности - не выполнялись.

### Запуск проекта
`go run main.go`

или

`go run .`

После запуска приложение будет доступно в браузере - <http://localhost:7540>

### Запуск тестов
`go test ./tests`

или более подробный вывод:

`go test ./tests -v`

После выполнения команды в консоли появится лог выполнения тестов.



#### Личный комментарий

Во время работы над проектом возникало довольно много трудностей.
Особенно непривычным оказался синтаксис Go и сам подход к написанию backend-части по сравнению с JavaScript, на котором я писал раньше.

Часто возникали ситуации, когда я понимал, как программа должна работать, но не сразу понимал, почему она не работает сейчас. Приходилось разбираться в ошибках, который было совсем не мало, но я рад, что у меня все получилось.

В целом это был очень полезный и интересный опыт!
